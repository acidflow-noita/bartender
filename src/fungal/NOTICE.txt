Fungal shift prediction and planning logic ported from:
https://github.com/liquidcake1/noita-fungal
Revision dd54fd7669b6a218e72bf500eade560173beff65
The original solver and other original contributions are dedicated to the public
domain under CC0: https://creativecommons.org/publicdomain/zero/1.0/
The source HTML/CSS UI is not included in this port.
shifts.js, materials.js, nolla-prng.js, and solver.js retain the source logic
verbatim; only relative import paths and this attribution header are adapted.
engine.js adapts the original index.html table calculations to data for native
Observable tables; goals.js contains its original constraint function unchanged.
The worker calls the source solver directly, without changed search ranges,
candidate pruning, probability weights, recipe sorting, or automatic job limits.
The source UI and solver use 20 iterations in all modes; the underlying source
prediction helper separately supports 200 in Hyper. The UI keeps the former.
Material options follow the source seed-generated Set, including Air and
custom additions, and accumulate across seed/mode changes. Bartender metadata
provides labels/images only; it never widens the selectable material set.

The shift engine and Nolla PRNG derive from Lymm's Telescope:
